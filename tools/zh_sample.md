# 测试用的中文文本

这个文件只用于测试：检查脚本用它确认分词器和模型在非英文、非代码的输入上也和参考实现一致。内容本身没有意义，但请不要改动它，因为参考数据是按这里的文字生成的，改了之后需要重新运行 `tools/ref_dump.py`。

## 一段说明文字

代码补全对延迟的要求很高。用户每敲几个字符，编辑器就会把光标前后的内容发给模型，等模型给出建议。如果建议在一两百毫秒内出现，用户会觉得它是跟着自己的思路走的；如果超过半秒，多数人已经自己把这一行写完了。

所以衡量补全服务快不快，首先看的是第一个 token 多久出来，其次才是后面每秒能生成多少个 token。一次补全通常只有十几到几十个 token，生成阶段本来就很短。

## 一张表
